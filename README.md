# BigBasket - Exploratory Data Analysis in Python
This project explores product level data from BigBasket dataset from Kaggle. The goal is to understand the data, uncover insights and demonstrate skills in data cleaning, manipulation, visualization and storytelling.

## Project objective:
1. Clean the data and structure raw data
2. Perform Exploratory and Deep Dive analysis
3. Derive business insights on product performance, pricing and customer satisfaction

## Tools used:
1. Python
2. Pandas
3. Seaborn, Matplotlib

## Highlights

### General EDA
- Top performing categories and brands by profit and rating

### Deep Dive analysis:
1. Product Segmentation - using price bins
2. Customer Satisfaction - using ratings
3. Overpriced products - high profit, low rating
4. Categories composition - Proportion of pdts in diff tiers
5. Value for money - high rating low price
6. Cost vs Rating analysis
